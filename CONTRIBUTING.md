# Contributing

Thanks for helping make Guardian more useful, understandable, and dependable.

## Before opening a pull request

1. Open the project in Android Studio and let Gradle sync complete.
2. Keep emergency guidance clear, actionable, and appropriately cautious.
3. Preserve the distinction between contacting a user's saved contacts and contacting official emergency services.
4. Do not add real personal phone numbers, location histories, API keys, signing keys, or other secrets to commits.
5. For map or model changes, preserve the relevant attribution and license notices.
6. Describe the change and how you checked it. For UI changes, include before/after screenshots when useful.

## Pull requests

- Keep each change focused and explain the user benefit.
- Note any permissions, setup, storage, or device behavior affected by the change.
- Avoid claiming a feature works across all devices unless that has been verified on them.
